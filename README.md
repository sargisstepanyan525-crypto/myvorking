# 🏛️ სოციალური აგენტის სამუშაო პორტალი (SSA Agent Simulator)

ინტერაქტიული ვებ-აპლიკაცია, რომელიც ახდენს **სსიპ სოციალური მომსახურების სააგენტოს (SSA)** სოციალური აგენტის სამუშაო პროცესის, დეკლარაციის შევსებისა და ოჯახების სოციალურ-ეკონომიკური მდგომარეობის შეფასების სიმულაციას.

---

## 🌟 ძირითადი ფუნქციონალი (Features)

* **📊 საინფორმაციო დაფა (Dashboard):** 
  * ჯამური სტატისტიკა (სულ განაცხადები, შეფასებული ოჯახები).
  * ბოლო აქტივობების რეალურ დროში ასახვა.

* **📝 ახალი დეკლარაციის შევსება (Declaration Form):**
  * ოჯახის უფროსისა და წევრების მონაცემების შეყვანა.
  * შემოსავლების, ქონებრივი მდგომარეობისა და სპეციალური სტატუსების (შშმ, პენსიონერი, მარტოხელა მშობელი) აღრიცხვა.

* **🧮 ქულის დათვლის ალგორითმი (Smart Rating Algorithm):**
  * შეყვანილი სოციალურ-ეკონომიკური მაჩვენებლების საფუძველზე სავარაუდო სოციალური ქულის ავტომატური დათვლა.

* **📋 განაცხადების მართვა (Case Management):**
  * შეფასებული ოჯახების სრული ცხრილი შესაბამისი ქულებითა და სტატუსებით.

* **💾 მონაცემთა შენახვა (Persistent Data):**
  * აპლიკაცია ინახავს შეყვანილ მონაცემებს ბრაუზერის `LocalStorage`-ში, რაც უზრუნველყოფს გვერდის განახლების შემდეგ მონაცემების შენარჩუნებას.

---

## 🛠️ გამოყენებული ტექნოლოგიები (Tech Stack)

* **HTML5** – სემანტიკური სტრუქტურა
* **CSS3** – CSS Variables, Flexbox, CSS Grid (Modern UI/UX)
* **JavaScript (Vanilla JS)** – DOM მანიპულაცია, ალგორითმები, LocalStorage API
* **Google Fonts** – Noto Sans Georgian (ქართული ენის მხარდაჭერა)
